Sources and method

The market-session close is verified against the Nifty 50 daily bar, while the breadth display is separately dated to TheWrap's weekly update. TradingView supplies the price and technical fields; company filings supply the selected fundamental claims. The indicators and support calculations are produced by the snapshot script, not estimated in prose.

Company results are reported on different calendars from market prices. A filing date is not the same as the end of the quarter it describes. The older Airtel quarter is specifically disclosed in the run notes because the next result was not yet available. A valuation field is a snapshot rather than a forecast. When an independent company page did not return a value, the report did not fill the missing cell from memory.

The chart and table extracts come from the same live Power BI dashboard, but their completeness must be checked separately. A visible row is not evidence that every row was collected. The counts, sector readings, source dates and any extraction limitations are recorded in the run files.
