Run notes and gate exceptions

The workflow requires a disclosure of every gate that the existing evidence cannot satisfy. Six exceptions apply to this batch. First, stale as-of dates, as the next table shows. Second, the shared ledger could not be used unchanged: for ASX the ledger's reverse DCF mixes New Taiwan dollar cash flow with a US dollar market value, so the dossier and its review packet were built from a per-company ledger copy in which only the reverse-DCF block differs; for UBER the ledger's free cash flow is lower than the filings show and the correction is disclosed in the dossier; for AXP and QCOM the ledger figure is shown unchanged with our own basis added beside it. The original ledger file was not changed. Third, secondary sources supplied some facts: third-party earnings-call transcripts, aggregator pages for consensus and report dates, two pages that returned HTTP 403 and were cached from a browser download, and a few news sites; the three-year median valuation for ASX, QCOM and AXP is our own computation. Fourth, some figures are not published and are shown as such, for example Qualcomm's three-year median multiple, Arm's margins, Uber's three-year median multiple and the ratings of two agencies whose pages were blocked. Fifth, scripts/validate_report.py accepts only market-intelligence and portfolio-audit reports, so it cannot run on a dossier; the readability, citation and Research Desk layout checks pass for all four, and the review packet does not run the validator for a dossier. Sixth, the shared dossier builder prints momentum-gate measurements as raw data, the review packet reads the label "RS" (relative strength) in that table as a ticker, and ASX's Layer 3 table cell is fixed text that the writer clarified in the paragraph beneath it; the repository's builder script itself was not changed.
