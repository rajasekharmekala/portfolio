Run notes and gate exceptions

The workflow requires a disclosure of every gate that the existing evidence cannot satisfy. Six exceptions apply to this batch. First, stale as-of dates, as the next table shows. Second, the shared ledger's Reverse DCF, consensus and fundamentals blocks were empty for all four funds, so the writers used per-company ledger copies filled only from fetched pages and clearly labelled as the index's or basket's values (Nasdaq-100 earnings for TQQQ, Dow earnings for UDOW, S&P 500 earnings for SPXL and the ten FANG+ companies for FNGU); prices, averages and the momentum gate were not touched. Third, secondary sources supplied some facts: the S&P Dow Jones Indices and Nasdaq methodology pages were blocked, so some index-level figures are N/A or come from fund pages and market-week articles that are labelled as secondary. Fourth, some figures are not published and are shown as such, for example the swap counterparty names for SPXL, the bid-ask spread for SPXL, UDOW and FNGU, the index-level stock pay for the Nasdaq-100, and any 30- and 90-day consensus history for an index. Fifth, scripts/validate_report.py accepts only market-intelligence and portfolio-audit reports, so it cannot run on a dossier; the readability, citation and Research Desk layout checks pass for all four. Sixth, the shared dossier builder prints momentum-gate measurements as raw data and does not wrap glossary terms that sit directly inside a paragraph; the writers applied a post-step in the run directory, and the repository's builder script itself was not changed.
