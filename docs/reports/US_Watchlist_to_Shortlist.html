Run notes and gate exceptions

Status: PUBLISHED_WITH_GATE_EXCEPTIONS for all four dossiers and this report. Each dossier repeats its own exceptions in a section before its sources.

Stale source dates. Every dossier cites prior-period filings, earnings calls and releases that are older than 60 days, and no newer version exists for the historical periods they describe. The citation checker was run with its stale-date allowance and printed an exception line for each record: SOFI 89, FXI 22, MSTR 43 and VRT 73. They lower confidence only in how current those specific figures are, and they clear as each company reports: SoFi on 2026-10-27, Vertiv on 2026-10-28 and Strategy on 2026-10-29. The ages count up each day, so they are one day higher in the final checker run than in the first.

Estimate data. Where the session ledger carried a reverse discounted-cash-flow figure it was checked against filings. SoFi's was kept after a check. Vertiv's was rebuilt on adjusted free cash flow excluding a one-off working-capital release. For FXI and MSTR the figure is not defined, because a fund has no cash flow and Strategy's cash flow is negative, and the dossiers say so and use substitutes (look-through earnings yield for FXI and the bitcoin price implied by enterprise value for MSTR).

Option prices. The recorded value of the SoFi calls ($550.10) is stale; a delayed live quote put them near $176. No other batch name has options in the book.

Verdict labels. The holding taxonomy has no label for a trim of an oversized position or for a hold with a pre-earnings trim. MSTR uses TRIM_PROFIT_BOOKING and Vertiv uses WAIT_FOR_SUPPORT as the nearest labels, and both dossiers disclose the deviation. The SoFi row's HOLDING_SEED label did not match the records.

Structural validator. The repository's structural validator for reports accepts only the market-report and portfolio-audit kinds, so it cannot return a pass for a company dossier. The readability check, the citation check, the review packet's code checks and the Research Desk layout check were run instead, and all passed.

Earnings dates. SoFi (2026-10-27), Vertiv (2026-10-28) and Strategy (2026-10-29) are company-confirmed. FXI has no earnings date because it is a fund. Each dossier labels its own.
