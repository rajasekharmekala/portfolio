1. The decision at a glance

The table gives each verdict under the repository's three-layer rules. Layer 1 tests the financial floors and the type of business (the archetype), Layer 2 scores three to five operating measures that run that business, and Layer 3 turns the chart into an entry rule and a position size. Reward-to-risk is the gain from the entry price to the base target divided by the loss from the entry price to the stop. The floor is 2.0 to 1 for Core Alpha names and 2.5 to 1 for tactical and turnaround names, so a name that clears the floor only at a lower price needs a limit order, not a market purchase. Where the rulebook has no exact label for a decision, the dossier says which label is nearest and where it does not fit.

Run notes and gate exceptions

Empty ledger expectations. Yahoo returned Too Many Requests while the ledger was built and on every retry over about three minutes, so the reverse DCF and consensus-revision fields are empty for all four names. Each writer solved the reverse DCF from filed cash flows with the repository solver and sourced consensus from fetched web pages where possible; consensus 30-day and 90-day revision history is N/A in every dossier because no verifiable source was found. The ledger cannot be repaired after the fact, so confidence in the expectations chapters is lower than for a run with the ledger fields filled. The cure is a rebuild of the ledger once the vendor lifts the limit. For labels only, the KEX, CINF, MSTX and MANH dossiers were built from a display copy of the ledger in which empty fields read "not available"; no numeric value was changed, and each dossier says so.

Stale as-of dates. The citation checker was run with the stale-as-of allowance. Stale records are research items whose period is more than 60 days before 2026-10-28, mostly fiscal-2025 annual filings and older price events: MANH 41, KEX 55, CINF 68 and MSTX 59. Each dossier lists its stale families, why they cannot be cured now (no newer periodic filing exists for that item) and what would cure them (the Q3 2026 10-Qs, expected in early November). Every as-of date is true; none was edited.

Next earnings dates. Manhattan's, Kirby's and Cincinnati's next report dates are not announced (the investor-relations pages returned 403 or an empty calendar), and the dossiers state the inferred windows as inferences. The Q3 2026 10-Q had not been filed for MANH, KEX or CINF at the as-of time, so the third-quarter figures rest on the earnings releases and call summaries.

Builder and tool limits. The scripts' first-use glossary pass skips a term that sits directly inside a paragraph; the MANH writer built through a run-scratch wrapper that applies the same rules with a corrected lookup and then calls the repository builder unchanged, and no repository file was edited. The builder has no slot between a heading and its table, so a few plain lead-ins were inserted by the wrapper, and a few builder-generated cells (for example the Core stop-rule wording that mentions Stage 1 bases, which the code check flags as a false positive for these Stage 2 names) could not be reworded. The reverse DCF solver rejects a negative cash flow, so MSTX has no reverse DCF (a fund has none).

Unverified inputs. Several three-year median multiples are medians of three year-end points from an aggregator page, peer multiples and some peer ROIC figures come from aggregators, and the Industrials sector-fund stage for KEX could not be confirmed from the ledger.
