Run notes and gate exceptions

The workflow requires a disclosure of every gate that the existing evidence cannot satisfy. Six exceptions apply to this batch. First, stale as-of dates, as the next table shows. Second, the shared ledger could not be used unchanged for two names: ORCX is a fund with no cash flows of its own, so its reverse-DCF and consensus blocks are empty and the dossier works at the level of Oracle; for TCEHY the ledger's free cash flow is in yuan but labelled in dollars, so the dossier was rendered from a per-company ledger copy in which only the reverse-DCF block differs (prices, averages and the momentum gate were not touched), and the original value is quoted in a note row. Third, secondary sources supplied some facts: earnings-call quotes for Amazon and Tencent come from third-party transcripts, the Oracle earnings date is shown only by aggregators and is unconfirmed, and the three-year median valuation for Tencent and MercadoLibre is our own computation from aggregator price history. Fourth, some figures are not published and are shown as such, for example Amazon's three-year median multiple, the wind-down terms of any US Treasury action on Tencent, and MercadoLibre's net debt to EBITDA excluding fintech funding. Fifth, scripts/validate_report.py accepts only market-intelligence and portfolio-audit reports, so it cannot run on a dossier; the readability, citation and Research Desk layout checks pass for all four. Sixth, the shared dossier builder prints momentum-gate measurements as raw data, places some headings directly above a table, and does not wrap glossary terms that sit directly inside a paragraph; the writers applied a post-step in the run directory, and the repository's builder script itself was not changed. The reviewers recorded the raw-data column as a note, not a finding, and each dossier discloses it.
