The four decisions, one at a time

Each paragraph states the rule behind the verdict, the number that triggered it and the level or event that would change it. The full working is in the linked dossier, with five-year tables, a peer comparison, growth scenarios and sources.

Data Patterns: deferred candidate, not shortlisted

Data Patterns builds defence electronics and has no debt. Its three-year cash flow is only 0.19 of profit, under the 0.25 red line, because receivables from long defence programmes keep growing. The dossier first judged that a breach, then re-read the relief clause, which fixes no number, and adopted a middle reading: the cash cycle is falling and the latest year, 0.30, clears 0.25. A stricter 0.50 bar would still give a rejection, and the dossier says this one choice decides the status. The company also fits no archetype today, and the shares trade at 79 times profit, so no order is possible and the zone is inactive.

Stylam Industries: deferred candidate, not shortlisted

Stylam makes decorative laminates, mostly for export, with almost no debt and a return on capital of 26.6 percent. The central value of ₹3,481.56 is only 12 percent above the close, which is about 6 percent a year over two years. Meeting the dossier's own 12 percent hurdle on the same target would need an entry near ₹2,775, below the stop. The new plant started late, domestic sales are flat and one operating test is graded FAIL. The earliest the checks can pass is after the FY27 accounts, about May 2027.

KFin Technologies: rejected

KFin is one of two large mutual fund registrars, with a return on capital of 29.2 percent and almost no debt. It is rejected because the Stage 4 line is met on the gate's own windows and on the ledger's stage code. One alternative reading, a 63-session window on the 50-day average, says that average is not falling, so the dossier calls the rejection conditional on the selector. Fee yield is falling 8 percent a year and the operating margin (profit from operations as a share of sales) fell from 41.5 to 34.2 percent. The ratio of 4.98 to 1 is hypothetical, because the price at which the Core floor holds, ₹835.46, is below the ₹861.50 that Test C needs.

CCL Products: deferred candidate, not shortlisted

CCL makes instant coffee for other brands and trades at 26.2 times profit, its lowest multiple in three years. The ledger's stage code reads Stage 4 and alone would reject it. The dossier instead applies the scoring file's wording with its own 63-session test, on which the 200-day average is still higher, so the clearance is contested and the gate status is PARTIAL. Every order and verdict upgrade needs a fresh ledger run that shows the test, the Stage 4 label, Test C and the shorter window together. A cut of under one turn in the multiple takes the ratio to the 2.0 floor.

Run notes and gate exceptions

This run published with gate exceptions. That means some checks could not be fully met with the evidence available. Each exception below names what failed, why it cannot be cured now, how it lowers confidence and what would cure it. The status of every dossier is PUBLISHED_WITH_GATE_EXCEPTIONS.

Data date. The run took place on Saturday 24 October 2026. The benchmark's 23 October bar was present and every batch name had a 23 October bar, so every price and technical level uses that session. News and results dated after that session are used in no gate or calculation.

Stale periodic filings. The latest periodic filing for each company is the quarter to 30 June 2026, between 8 and 92 days old, so the citation check lists many records as EXCEPTION AS-OF lines. Each dossier lists each group with its age and cure. The cure is to rerun the research once the September-quarter results are filed.

Ledger fields. The ledger has no reverse DCF or consensus revisions for these names, so each dossier states its own recompute beside the ledger's value and labels it a price-implied diagnostic. Several figures rest on secondary readings, such as pledge histories read through aggregators, and are labelled where used. The ledger's support anchor for each name is the 23 October session low, not a tested floor, and the builder prints a template label "verified support" that the dossiers disclose or relabel.

Validator mismatch. The shared structural validator has only market-report and portfolio-audit modes. Run on a single-company dossier, it fails a check built for those formats, which asks for case notes for all holdings, and it prints one to three template bridge warnings. The review packet code skips it for dossiers, and no script was modified. The readability check also looks for estimate parts and a Chapter 7 that this summary does not carry, because the dossiers do. The cure is a dossier mode in the validator and a summary mode in the readability check.

Reviewer gate. All four dossiers received REVISE in round 1 from the reviewer, and all four received REVISE again in round 2, so every dossier closed as BEST_EFFORT_AFTER_REVIEW_LIMIT, with the remaining findings fixed afterwards without a third review. The red team approved Stylam and CCL in round 2, and held the verdict for Data Patterns and KFin with one or two findings each, which were fixed. This summary report was not reviewed separately.

Judgment calls. The Data Patterns status rests on the 0.25 versus 0.50 reading of a relief clause that fixes no number. The KFin rejection and the CCL deferral rest on the dossiers' own selector for the word "falling", which the scoring file does not define. If the repository owner confirms a different reading, those labels would change with the same reopening steps.

Source quality. One company agent read SEBI pages with certificate checks off, and the dossier says the integrity of those copies is not verified and that no figure rests on them alone. Another research agent kept its page copies in its own folder and did not touch the shared cache.

Holding labels. The verdict list has no hold-and-wait label, so the routing rule's WAIT_FOR_SUPPORT is applied to pipeline names and printed with its plain meaning. The orchestrating agent could not start nested subagents, so the four company agents and the reviewers ran as separate sessions, one per company.
