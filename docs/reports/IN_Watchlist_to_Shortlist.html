What each name showed

The first test is a set of six hard floors. Each name must pass all of them before any scoring starts. The floors cover return on capital employed (ROCE), which shows the profit earned on the money the business uses, along with debt, cash conversion, the price trend and the upside-to-downside ratio. The price trend uses stages: Stage 4 is a markdown, when the price falls below averages that are falling, and a base is a flat period after a fall where a stock builds before a move. A name that fails any one floor is rejected, and its later checks are not run.
