The four decisions, one at a time

Each paragraph states the rule behind the verdict, the number that triggered it and the level or event that would change it. The full working is in the linked dossier, with five-year tables, a peer comparison, growth scenarios and sources.

KRBL: deferred candidate, not shortlisted

KRBL sells basmati rice under the India Gate brand and has almost no debt. Its auditors have given a qualified opinion on the FY26 accounts and the June 2026 review because of an Enforcement Directorate money-laundering case, which the dossier treats as an unresolved allegation and not a finding. The June 2026 quarter was lifted by high prices and investment gains that management calls not sustainable, so normal earnings are nearer ₹28 a share, about 12.5 times and not the 10.6 times printed. The central value of ₹456.38 needs the multiple to rise from about 10.5 to 13.3 times. Any order would need seven checks, including a passing momentum gate and a rerun of the stop and size, and the dossier sets the hypothetical maximum at 331 shares.

Elecon Engineering: rejected

Elecon makes industrial gearboxes and material-handling equipment, with no pledge and about ₹700 crore of net cash. It is rejected because the scoring file's Stage 4 wording is met when "falling" is read as strictly below the level 63 sessions earlier: the 50-day average is ₹436.67 against ₹511.77, and the 200-day is ₹453.11 against ₹481.33. That window is the dossier's own choice, since the file does not define the word. The gate's own 21-session window reads the 50-day average as rising, and the ledger's stage code reads Stage 1, so the dossier calls the rejection conditional and asks for an authoritative clarification. A close at or above the 50-day average would reopen research only, and no order is possible without a full rerun.

Marksans Pharma: deferred candidate, not shortlisted

Marksans makes store-brand and generic medicines, mostly for the US, UK and Europe, and holds net cash. It scores 4.0 of 5.0 and breaks no red line, but its three-year cash conversion is 0.80, and 0.705 on the strictest lease-adjusted reading, only 0.005 above the dossier's own 0.70 bar. The zone top of ₹285.15 clears the 2.5 floor, yet the probability-weighted return there is 5.9 percent, under the dossier's own 12 percent hurdle, so the hurdle must be met again after the 4 November results before any order. Promotion to shortlisted also needs facility-matched primary FDA evidence for each plant, and the FDA's own databases were not queried.

Aeroflex Industries: deferred candidate, not shortlisted

Aeroflex makes stainless-steel flexible hoses and, increasingly, liquid-cooling units for data centres sold to one buyer. It carries no debt, but the shares trade at 89 times trailing profit, and the central 12-month value of ₹427.56 is under the ₹451.30 price. The gate status is PARTIAL because the routing rule's positive clause is not met. About ₹51 crore of tax and duty demands are open, and only ₹41.76 crore of that is under appeal. The zone of ₹415 to ₹435 and the ₹414.03 stop are inactive planning levels, and orders wait for the 28 October results, a date the company has not confirmed in the sources read.

Run notes and gate exceptions

This run published with gate exceptions. That means some checks could not be fully met with the evidence available. Each exception below names what failed, why it cannot be cured now, how it lowers confidence and what would cure it. The status of every dossier is PUBLISHED_WITH_GATE_EXCEPTIONS.

Data date. The run took place on Saturday 24 October 2026. The benchmark's 23 October bar was present and every batch name had a 23 October bar, so every price and technical level uses that session. News and results dated after that session are used in no gate or calculation.

Stale periodic filings. The latest periodic filing for each company is the quarter to 30 June 2026, between 71 and 87 days old, so the citation check lists many records as EXCEPTION AS-OF lines. Each dossier lists each group with its age and cure. The cure is to rerun the research once the September-quarter results are filed.

Ledger fields. The ledger has no reverse DCF or consensus revisions for these names, so each dossier states its own recompute beside the ledger's value and labels it a price-implied diagnostic. Several figures rest on secondary readings, such as pledge histories read through aggregators and single undated analyst estimates, and are labelled where used. The ledger's support anchor for each deferred name is the 23 October session low, not a tested floor, and the builder prints a template label "verified support" that the dossiers disclose.

Validator mismatch. The shared structural validator has only market-report and portfolio-audit modes. Run on a single-company dossier, it fails a check built for those formats, which asks for case notes for all holdings, and it prints one to three template bridge warnings. The review packet code skips it for dossiers, and no script was modified. The readability check also looks for estimate parts and a Chapter 7 that this summary does not carry, because the dossiers do. The cure is a dossier mode in the validator and a summary mode in the readability check.

Reviewer gate. All four dossiers received REVISE in round 1 from the reviewer. In round 2 the reviewer returned REVISE again for all four, so every dossier closed as BEST_EFFORT_AFTER_REVIEW_LIMIT, with the remaining findings fixed afterwards without a third review. The red team approved Marksans in round 2 and Aeroflex in round 1, and held the verdict for KRBL and Elecon with one finding each, which was fixed. This summary report was not reviewed separately.

Elecon reading. The Elecon rejection rests on the dossier's own 63-session reading of "falling". On the gate's own 21-session window the first limb is not met, and the ledger stage code reads Stage 1. If the repository owner confirms the stage-code reading, the label would become a discretionary no-order wait with the same reopening steps.

Holding labels. The verdict list has no hold-and-wait label, so the routing rule's WAIT_FOR_SUPPORT is applied to pipeline names and printed with its plain meaning. The orchestrating agent could not start nested subagents, so the four company agents and the reviewers ran as separate sessions, one per company.

Cache note. The shared page cache keys each entry without the query string, so exchange announcement links that differ only by query string share one entry. One company agent also reformatted the whitespace of cached pages in that shared cache without changing their content, which other runs may have noticed.
