Primer: how to read this dossier

Terms: RSI is relative strength index; ATR is average true range; ROCE is return on capital employed.

A base is a flat price area; pivot is a key price level; breakout is a move above that level; retest is a later check of that level; asymmetry is the gain set against the loss; debt-to-equity is debt divided by equity.

A pass needs proof, a fail has a cause, and a watch has a test, so read the date, price, source and note before you act.
