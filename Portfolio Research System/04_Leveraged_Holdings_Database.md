## Entry and Add Discipline

Leveraged exposure is only added when the underlying has verified support or a
clean breakout retest, with the relevant moving-average alignment, stop,
volatility buffer, and maximum loss defined first. Never chase an extended
underlying or average down a broken trend. If support, ATR, liquidity, or the
invalidation level cannot be verified, retain cash and mark the setup
`DEFER / RESEARCH_REQUIRED`.

# Monitoring Framework

| Metric | Daily / regular question | Status |
| --- | --- | --- |
| Underlying trend | Above/below key moving averages? Higher highs/lows intact? |  |
| Momentum | RSI/MACD/breadth confirming or diverging? |  |
| Market regime | Risk-on, risk-off, high-volatility or transition? |  |
| Macro / catalyst | Rates, earnings, policy or event changing thesis? |  |
| Drawdown | Is loss within planned tolerance for this instrument? |  |
| Profit protection | Has a substantial gain coincided with trajectory deterioration? |  |
| Overlap | Is the same thesis already expressed elsewhere? |  |
